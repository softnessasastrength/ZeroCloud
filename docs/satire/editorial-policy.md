# Satire and editorial policy

ZeroCloud is an independent educational and satirical cloud project. It is not affiliated with Amazon or AWS.

**The infrastructure is real. The corporation is fictional.**

Humor targets cloud-marketing excess, bureaucracy, and the mismatch between enterprise claims and tiny hardware. The implementation and security documentation must remain technically truthful.

- Do not copy AWS logos, proprietary UI assets, internal documentation, confidential material, or trade dress.
- Do not publish identifiable employee information or personal records.
- Use original service names and branding.
- Distinguish fictional SLAs, invented incidents, and mock customer billing from real measured behavior.
- Clearly label all mock incident reports as fictional.
- Never use jokes to conceal real operational limitations.
