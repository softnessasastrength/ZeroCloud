# ClankerWorks departments

This directory holds detailed, version-controlled charters for the fictional ZeroCloud corporation.

- [Department blueprint](DEPARTMENT_BLUEPRINT.md): organization-wide reporting lines, artifacts, and proposed future departments.
- [Finance](FINANCE.md): synthetic currency, budgeting, segregation of duties, accounting controls, mock procurement, and audit.

Each future department should document:
1. Purpose, mandate, and explicitly excluded real-world authority.
2. Org chart, role IDs, personnel file links, and conflict-of-interest rules.
3. Input/output work orders, service expectations, and measurable acceptance criteria.
4. Mock inbox, event types, approval paths, and escalation.
5. Data schema, retention, auditability, and security boundary.
6. Failure modes and controlled behavioral variations.
7. Scenario fixtures, test plan, and observable metrics.
8. Status (proposal, implemented, tested, deployed), with evidence for each claim.

The company is a sandbox. Its bureaucracy is not a security boundary; enforce permissions in the runtime.
