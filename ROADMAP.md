# ZeroCloud roadmap

## Stage 0: Source of truth
- [x] Initialize GitHub repository
- [ ] Review and merge architecture documentation PR
- [ ] Decide hardware certification scope (Decision 008)
- [ ] Inventory R630 and actual network equipment
- [ ] Establish issue templates, CI checks and documentation standards

## Stage 1: Hardware research
- [ ] Freeze hardware tournament protocol and candidate list
- [ ] Obtain candidates and document full acquisition cost
- [ ] Qualify stock K3s on individual boards
- [ ] Publish raw benchmark and endurance results
- [ ] Record reference SBC selection in an ADR

## Stage 2: Three-node pilot
- [ ] Provision three identical qualified SBCs
- [ ] Configure isolated managed Ethernet and K3s cluster
- [ ] Demonstrate ARM64 workload lifecycle and scheduling
- [ ] Implement observability, recovery exercises and measured resource limits

## Stage 3: Miniature cloud services
- [ ] Accounts/projects and identity
- [ ] Instance API and console
- [ ] Storage design and implementation after ADR
- [ ] Fictional usage metering and billing
- [ ] Backups, security review, CI and operational runbooks

## Stage 4: Expand and publish
- [ ] Qualified hardware expansion and optional heterogeneous instance families
- [ ] Satirical public documentation and product pages
- [ ] Explicitly measured SLOs and incident postmortems

Nothing in this roadmap is a claim of completed deployment unless checked with evidence.
