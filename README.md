# ZeroCloud

**A tiny, functional cloud with an unreasonably serious attitude.**

ZeroCloud is an independent, tongue-in-cheek miniature cloud platform built around a Dell PowerEdge R630 control plane and a qualified fleet of single-board-computer workers.

> The infrastructure is real. The corporation is fictional.

## Status

**Architecture and hardware qualification planning.** No physical cluster deployment, reliability target, or service implementation has yet been verified.

The project plans to use managed wired Ethernet, stock K3s qualification, standardized worker hardware initially, and eventual heterogeneous SBC support. The reference board will be chosen through reproducible hardware testing.

See the architecture decision records and roadmap in the documentation foundation pull request.
